Verificación del cumplimiento de alcance:
Objetivo
Verificar el nivel de avance del sistema según el alcance establecido desde un principio.
Durante el desarrollo del sistema de gestión de citas médicas se logró implementar una gran parte de las funcionalidades principales planteadas en el alcance inicial del proyecto. Actualmente el sistema cuenta con:
•	Desarrollo de un sistema web.  
•	Visualizar una agenda mostrando días y horas disponibles para una cita médica. 
•	Registrar, editar y eliminar citas médicas. 
•	Confirmar, cancelar y reprogramar citas. 
•	Llevar un control y seguimiento del estado de las citas (asistidas, no asistidas, canceladas y reprogramadas). 
•	Definir roles básicos del sistema para pacientes y personal del consultorio (doctor y asistente). 
•	Organizar los horarios disponibles y la duración estimada de las consultas. 
Los que aun no han sido cumplidos:
• Enviar recordatorios automáticos a los pacientes. 
El alcance del proyecto se encuentra en etapa final, debido a que la mayoría de funciones principales ya están implementadas, permitiendo contar con una versión casi completa. No obstante, aún falta agregar la última función.
Conclusión:
Se logró desarrollar una base sólida y funcional del sistema, cumpliendo con gran parte del alcance planeado. 
Aun así, el proyecto requiere continuar con correcciones, optimizaciones y finalización de módulos pendientes para alcanzar una versión más estable, organizada y completa.
